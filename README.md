# bank-biznes-kreditleri-powerbi
Bank biznes kreditləri portfelinin Power BI dashboardu: PAR30, PAR60, PAR90, NPL 90+, Stage 2 payı, ehtiyat örtüyü (coverage ratio), inflow və borclanan konsentrasiyası. Məlumatlar anonimdir və generasiya olunmuş datalardır.
Əsli ilə oxşarlıqlar təşkil edir ancaq orginal data deyildir.
